# Data

Following the unit's practice:

* `data/raw/` — datasets exactly as published: downloaded, never edited.
  **Not committed**; `report/01-Data.ipynb` re-creates it.
* `data/processed/` — anything derived, made by code (cleaned data, splits,
  embeddings). **Not committed**; regenerate it.
* `data/output/` — final outputs: figures, tables and timing results.

Commit the code that makes these files, not the raw or processed files
themselves (GitHub size limits, and binary data bloats the history). The same
goes for model weights: download or retrain them in code.
